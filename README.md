## RackNerd 与 Hetzner 对比：5 个最该看的差异

不啰嗦，直接上干货。下面这 5 个维度是我每次帮人选 VPS 时真正会卡住的地方，不是那种泛泛而谈的"都很优秀"。

**1. 计费方式：年付锁定 vs 按小时弹性**
这是两家的根本差异。RackNerd 的特价套餐基本是 **年付一次性付款**，价格压得很低但钱一次掏出去；Hetzner 走的是 **按小时计费、有月度封顶**，用几天算几天，临时跑个测试三天关掉，账单也就几毛钱。如果你不确定这个项目能活多久，Hetzner 的弹性明显更友好；如果是长期挂站、自用代理、跑常驻服务，RackNerd 的年付一次锁死反而省心。

**2. 机房位置：20 个 vs 6 个**
RackNerd 官方列了 **20 个数据中心**，覆盖洛杉矶、圣何塞、西雅图、达拉斯、纽约、芝加哥、亚特兰大、阿什本、坦帕、多伦多、纽约、犹他、阿姆斯特丹、伦敦、都柏林、斯特拉斯堡，亚洲方向有洛杉矶 Asian Optimized 线路可选。Hetzner 的云服务器在 **6 个地区**：德国（法尔肯施泰因、纽伦堡）、芬兰（赫尔辛基）、美国（俄勒冈 Hillsboro、弗吉尼亚 Ashburn）、新加坡。如果你的用户主要在欧洲，Hetzner 的德国和芬兰机房延迟低到飞起；如果用户在亚太或者你要美国 IP，RackNerd 的洛杉矶节点更顺。我自己用过 RackNerd 的洛杉矶 DC，国内回程走 CN2 方向，晚高峰也没明显掉速。

**3. 性能配置：共享 vCPU 各有各的算法**
两家都是共享 vCPU，但配置分布不一样。RackNerd 的服务器跑 Intel Xeon，存储是 **纯 SSD + RAID-10**，网络端口 **1Gbps**，SolusVM 控制面板能重启、重装、改 rDNS。Hetzner 用 Intel/AMD 混合，存储是 SSD，网络也是 1Gbps 起步，控制台是自家的 Cloud Console，API 支持比较完整。实际跑下来，CPU 单核成绩两家差不多，Hetzner 的欧洲机房因为用户密度低、邻居干扰少，跑分波动更小一些；RackNerd 节点多、负载分布广，但偶尔会遇到邻居抢资源的情况——这种情况开个工单换个节点就行。

**4. 价格门槛：年付压价 vs 欧元计费**
最直观的差距在这。RackNerd 年付特价里，最低的 1GB 套餐 **$21.99/年**，平均每月不到 $2；最贵的 8GB 套餐 **$119.99/年**，平均月 $10。Hetzner 最低的 CX22 是 **€3.79/月**（2 vCPU、4GB RAM、40GB 存储、20TB 流量），折算成人民币大概三十多块一个月。粗算的话，同是 4GB 这一档：RackNerd 年付 $59.99（约 ¥480/年，月均 ¥40），Hetzner CX22 月付 €3.79（约 ¥30/月，年化 ¥360），Hetzner 单看月费更低。但 Hetzner 是月付随时可取消，RackNerd 是年付锁定——**Hetzner 用满一年便宜，但中途不用了没退款压力；RackNerd 用满一年最省，但钱已经先花出去了**。这是两种完全不同的成本结构，别只看数字。

**5. 流量配额：递增 vs 20TB 一把梭**
RackNerd 特价套餐的流量是 **按 RAM 递增** 的：1GB 给 3TB，2GB 给 5TB，4GB 给 7TB，6GB 给 12TB，8GB 给 20TB。Hetzner 不管哪个套餐，**统一都是 20TB 出站流量**。如果你跑的是大流量站点或者中转代理，Hetzner 的 20TB 最低配就能顶 RackNerd 最高配的量；但如果你只是挂个小博客、跑个监控，RackNerd 3TB 也够用，而且超量了 RackNerd 一般是限速不是直接断网。

## RackNerd 适合谁，Hetzner 又适合谁

不同的人选 VPS 看的东西不一样，别只盯着价格看。

**该选 RackNerd 的场景**
- 长期挂站、个人博客、自用代理、跑监控或常驻服务，能接受一次付一年
- 用户或访问来源在亚太，需要美国西海岸节点（洛杉矶 Asian Optimized 是它家明星线路）
- 预算极度敏感，每月能省几块是几块，能接受年付锁定换低价
- 想要多节点可选，未来可能要切机房试延迟

**该选 Hetzner 的场景**
- 用户在欧洲，延迟敏感，需要德国或芬兰本地机房
- 项目周期不确定，临时跑测试或短期部署，按小时计费更灵活
- 大流量场景，20TB 出站起步够用，不想被 RackNerd 低配的 3TB 卡住
- 在意 GDPR 合规、ISO/IEC 27001 认证这种企业级背书

我自己手上同时跑着两边：博客和小工具放 RackNerd 洛杉矶年付，几个欧洲用户的项目临时部署在 Hetzner CX22 上。两边各管一摊，没觉得哪个能完全替代另一个。讲真，纠结哪边"更好"意义不大，关键是看你这个具体场景往哪边靠。
